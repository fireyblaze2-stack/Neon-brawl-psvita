NEON BRAWL - portable package
=============================

Contents
  index.html   The complete game (single file, no dependencies, works offline)

How to run
  Desktop : double-click index.html (Chrome, Edge, Firefox, Safari).
  Phone   : copy the file to the device and open it in the browser,
            or host it on any static web server.
  Vita    : open the hosted page in the Vita's built-in browser, or use
            this folder as the web payload for a Vita HTML wrapper app.
            (This package is NOT a compiled .vpk; building one needs VitaSDK.)

Controls
  P1: Arrows move, Z punch, X jump, C swap weapon
  P2: WASD, F punch, G jump, H swap (press F to join)
  Gamepad and touch controls are supported.
